# Explicaí · brand book

Identidade visual e verbal do [Explicaí](https://github.com/gabriel-codesampaio/explicai), o construtor de manuais open source e gratuito.

Página publicada: https://gabriel-codesampaio.github.io/explicai-brandbook/

O que tem no brand book: essência e posicionamento, personalidade, regras do nome, logo e família (Studio e Agent), cores para tema claro e escuro, tipografia, voz, narrativa e as primeiras peças.

Tudo fica em um único `index.html`, sem build. As fontes vêm do Google Fonts.

## Arquivos do logo

Ficam em [`logo/`](logo/). Os SVGs têm as letras convertidas em contorno, então funcionam sem a fonte instalada.

| Arquivo | Uso |
|---|---|
| `explicai-logo-horizontal.svg` / `.png` | Logo principal em fundo claro |
| `explicai-logo-horizontal-escuro.svg` / `.png` | Logo principal em fundo escuro |
| `explicai-agent-logo-horizontal.svg` | Logo do Agent |
| `explicai-wordmark.svg`, `explicai-wordmark-branco.svg` | Só o nome |
| `explicai-simbolo.svg`, `explicai-icon-512.png` | Símbolo do Studio |
| `explicai-agent-simbolo.svg`, `explicai-agent-icon-512.png` | Símbolo do Agent |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Favicon e atalho no celular |
| `social-preview.png` | Prévia no GitHub e em redes (1280 × 640) |
